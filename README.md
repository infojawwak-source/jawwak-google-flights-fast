# Jawwak Google Flights - Swoop

Standalone Google Flights search service for Jawwak.

Install with `pip install -r requirements.txt`.

Endpoints:
- GET `/api/health`
- POST `/api/search-flights`
- POST `/api/price-selector`

No API key is required.

Swoop uses undocumented Google Flights endpoints; Google may change or rate-limit them.
